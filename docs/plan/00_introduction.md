# 00. プロジェクトの紹介

## 目的と背景

Chromiumベースのブラウザ（Google Chrome, Brave, Edge, さらにはAtlas, Dia, Cometといった新しいAIブラウザ）で、Arcブラウザのような先進的なユーザー体験を実現する拡張機能を開発します。

このプロジェクトは、既存のオープンソース拡張機能「Arcify」（GPL-3.0）にインスパイアされています。Arcifyは素のJavaScript, HTML, CSSで構築されていますが、本プロジェクト「Arcline」では、React, TypeScript, Vite, Zustandといったモダンな技術スタックを採用し、パフォーマンス、保守性、そしてユーザー体験を大幅に向上させることを目指します。

## 到達目標（MVP）

最小限の実行可能な製品（MVP）として、以下の機能を実現します。

1.  **垂直タブUI**: サイドパネルに常駐し、タブを縦に一覧表示・管理できるUI。
2.  **スペース機能**: 作業コンテキスト（例：「研究」「仕事」）ごとにタブの集合を切り替え、不要なタブは休止させる機能。ブックマークとの連携も含む。
3.  **コマンドパレット**: `Ctrl/Cmd+K`で起動し、スペース、タブ、履歴などを横断的に検索して即座に移動できる機能。
4.  **モダンなアニメーション**: Arcブラウザのような、滑らかで直感的なアニメーション（タブの並べ替え、スペースの切り替えなど）。
5.  **基本要件**:
    *   **最小権限**: 必要最小限のAPI権限のみを要求します。
    *   **パフォーマンス**: 高速に動作し、ブラウザのメモリ消費を抑えます。
    *   **安定性**: 堅牢な設計で、クラッシュや不具合を最小限に抑えます。
    *   **ライセンス準拠**: GPL-3.0ライセンスに準拠し、適切な法的告知を行います。
    *   **アクセシビリティと国際化**: キーボード操作を完備し、多言語（まず英語と日本語）に対応します。
