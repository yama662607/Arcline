# Arcline - 既知の問題と制限事項

## 現在の既知の問題

### フローティング UI

#### Atlas ブラウザでの制限
- **問題**: Atlas の独自 UI が一部競合する可能性があります
- **影響**: フローティング UI の表示位置が意図しない位置にずれる場合があります
- **回避策**: ブラウザウィンドウをリサイズすると正常な位置に戻ります
- **優先度**: 中
- **予定**: 将来のバージョンで Atlas 固有の調整を実装予定

#### コンテンツスクリプト非対応ページ
- **問題**: `chrome://` や `edge://` などの内部ページではコンテンツスクリプトが動作しません
- **影響**: これらのページではフローティング UI が表示されません
- **回避策**: ポップアップ UI を使用してください
- **優先度**: 低（仕様制限）
- **予定**: 回避策の改善を検討中

### スペース管理

#### タブの順序変更
- **問題**: タブをドラッグ&ドロップで並び替えた際、Chrome API の制限により完全な順序制御ができない場合があります
- **影響**: 期待した順序と異なる配置になることがあります
- **回避策**: タブを手動で再配置してください
- **優先度**: 中
- **予定**: Chrome Extensions API の拡張を待つか、代替実装を検討

#### スペース削除時の動作
- **問題**: 最後のスペースは削除できません
- **影響**: 常に1つ以上のスペースが存在します
- **回避策**: なし（意図的な仕様）
- **優先度**: なし
- **予定**: なし

### パフォーマンス

#### 大量タブでの動作
- **問題**: 1つのスペースに100タブ以上存在する場合、描画が遅延する可能性があります
- **影響**: UI のスクロールやタブ切り替えが若干遅くなります
- **回避策**: タブを複数のスペースに分散させてください
- **優先度**: 低
- **予定**: 仮想スクロールの最適化を検討

### ブックマーク同期

#### 重複ブックマークの処理
- **問題**: 同じURLを複数のスペースでピン留めすると、ブックマークが重複する場合があります
- **影響**: ブックマークマネージャーに同じURLが複数表示されます
- **回避策**: 手動で重複を削除してください
- **優先度**: 低
- **予定**: 重複検出と自動マージ機能を実装予定

### アーカイブ機能

#### アーカイブ上限
- **問題**: アーカイブできるタブは最大100件です
- **影響**: 100件を超えると古いアーカイブから自動削除されます
- **回避策**: 重要なタブはブックマークに保存してください
- **優先度**: 低
- **予定**: 設定可能な上限値の実装を検討

## ブラウザ別の制限事項

### Chrome
- すべての機能が正常に動作します
- Chrome 116 以上が必要です

### Atlas
- Side Panel API が利用できないため、フローティング UI のみが利用可能です
- 一部の UI 要素が Atlas の独自スタイルと競合する可能性があります

### Arc
- フローティング UI が推奨モードです
- Arc 独自のスペース機能との統合は現在サポートされていません

### Edge
- 基本的に Chrome と同じ機能が利用可能です
- Edge 116 以上が必要です

### Brave
- 基本的に Chrome と同じ機能が利用可能です
- Brave の広告ブロック機能が一部の UI 要素に影響する可能性があります

## 報告された問題

問題を発見した場合は、以下の情報と共に GitHub Issues で報告してください：

1. **環境情報**
   - OS（Windows/Mac/Linux）
   - ブラウザとバージョン
   - Arcline のバージョン

2. **問題の詳細**
   - 発生した問題の説明
   - 再現手順
   - 期待される動作
   - 実際の動作

3. **追加情報**
   - スクリーンショット（可能な場合）
   - コンソールのエラーメッセージ（可能な場合）
