## English Store Listing (`en`)

**Extension Name** [REQUIRED]
`__MSG_extName__` → **Arcline**

**Short Description** [REQUIRED] (`<= 132` chars; `114` chars in `_locales/en/messages.json`)
Arc-style vertical sidebar with Spaces, global Favorites, left-edge hover, and a unified Command Bar new tab page.

**Detailed Description** [REQUIRED]
Arcline brings an Arc Browser-inspired vertical sidebar and unified Command Bar new tab page to Chrome and Brave — lightweight, bilingual (English & Japanese), and 100% local-first.

Key Features

Left-Edge Auto-Hide Hover & Native Side Panel Sync
Keep 100% of your screen for webpages. Move your cursor to the left edge of any webpage to slide out the frosted-glass sidebar, and move away to hide it automatically. Arcline stays zoom-invariant when zooming pages and unloads inactive background frames to keep RAM low. On internal browser pages (`chrome://`, `brave://`) where floating overlays cannot run, Arcline switches seamlessly to Chrome's native Side Panel with matching rounded styling.

Arc-Style Unified Command Bar & New Tab Page
Open a new tab to launch a fast keyboard-first Command Bar that fuses open tabs ("Switch to Tab"), Global Favorites, Space pinned folders, browser History, archived tabs, quick browser actions, and colored Site Search shortcuts (`gh `, `yt `, `wiki `, `gpt `, `pplx `, `g ` + Tab). Choose Google, DuckDuckGo, or Brave Search as your fallback engine.

Global Favorites & Bookmark-Backed Spaces
Pin your everyday web apps once at the top of the sidebar and access them from any Space with live audio mute/unload controls. Organize permanent links in nested Space folders stored natively in your browser's bookmarks ("Other Bookmarks / Arcline"), ensuring zero data loss across restarts.

Two-Finger Swipe & Space Theme Studio
Swipe horizontally with two fingers over the sidebar to switch Spaces without triggering browser Back/Forward history navigation. Customize each Space with multi-point color gradients, harmony modes, vibrancy controls, subtle film grain, and per-Space Light or Dark mode.

Bilingual UI, 4-Step Start Guide & 1-Click Arc Import
Instant English and Japanese localization (`Auto`, `English`, `日本語`), a 4-step interactive onboarding walkthrough on install, automatic idle-tab archiving, and 1-click import from Arc's `StorableSidebar.json`.

Permissions Used (100% Local)
- "Read and change all your data on all websites": Used solely to display the left-edge hover trigger and sidebar overlay on web pages. Page content is never read or transmitted.
- "Read and change your bookmarks": Saves your Favorites, Spaces, and pinned folders under Other Bookmarks / Arcline.
- "Read your browsing history": Searches past visited pages inside the unified Command Bar new tab alongside your open tabs and bookmarks.

Privacy & Support
Arcline makes zero outbound network requests and includes no analytics or tracking. Report issues or feedback at https://github.com/yama662607/Arcline/issues

## 日本語ストア掲載文 (`ja` / ローカライズ用)

**拡張機能名**
**Arcline**

**概要（短い説明）** (`57` 文字 / 上限 `132` 文字以内)
Arc風の縦型サイドバー。Space、共通お気に入り、左端ホバー表示、コマンドバー付き新規タブページを提供します。

**詳細な説明**
Arcline は、Arc Browser の洗練された縦型サイドバー体験と「お気に入り・タブ・履歴融合コマンドバー」を、超軽量・テレメトリゼロの環境で Chrome / Brave に再現するオープンソース拡張機能です。

主な機能

1. 左端ホバー自動表示オーバーレイ ＆ ネイティブサイドパネル連携
普段は幅 0px で隠れており、画面左端にカーソルを近づけた瞬間だけすりガラス製のサイドバーが滑らかに展開します。ページの拡大・縮小（Cmd+/Cmd-）を行っても UI サイズが崩れず、非アクティブタブではメモリを自動解放します。設定ページや拡張機能管理ページ（chrome:// / brave://）でも Ctrl+B や Space 切替に連動し、同じ角丸カードデザインでネイティブサイドパネルが開きます。

2. お気に入り・ピン留め・タブ・閲覧履歴を融合した Arc 風コマンドバー新規タブ
新しいタブを開くと、開いているタブへの「タブに切替 ↗」、全 Space 共通のお気に入り、Space ごとのピン留めリンク／フォルダ、過去の閲覧履歴、クイックコマンド、さらに専用チップ検索（gh / yt / wiki / gpt / pplx / g + Tab）を 1 か所から高速に検索・実行できます。

3. 消えない Favorites & ブックマーク連動 Spaces
お気に入りや Space ごとの階層フォルダはブラウザ標準のブックマーク（「その他のブックマーク / Arcline」）に保存されるため、ブラウザ再起動や拡張の更新でもデータが失われません。

4. 2本指横スワイプ切替 ＆ Space テーマスタジオ
サイドバー上での 2 本指トラックパッド操作だけで、Web ページの戻る／進むと競合することなく Space を往復できます。テーマスタジオでは 1〜3 色のグラデーション配置、調和モード、鮮やかさ、フィルム粒子ノイズ、Space 別ライト／ダークを細かく設定できます。

5. 日英バイリンガル対応 ＆ 初回スタートガイド ＆ Arc ワンクリック移行
インストール直後に 4 ステップの導入ガイドが開き、UI 言語もワンクリックで英語／日本語をリアルタイム切替可能。Arc の StorableSidebar.json からの一括移行や、一時タブの自動アーカイブ機能も備えています。

プライバシーについて
Arcline は外部サーバーへの通信や利用統計の収集を一切行いません。すべての設定・履歴検索・ブックマーク管理はお使いのデバイス内で完結します。

サポート・ご要望: https://github.com/yama662607/Arcline/issues

## Permissions Justification

| Permission | Type | Justification |
| --- | --- | --- |
| `sidePanel` | permissions | Required to display the Arcline vertical sidebar inside Chrome's native Side Panel on restricted pages (`chrome://`, `brave://`) and when toggled via toolbar click or keyboard shortcut. |
| `tabs` | permissions | Required to list open tabs in the sidebar and Command Bar, focus/switch active tabs across windows, display audio playback status, mute/unmute tabs, and manage Space tabs. |
| `tabGroups` | permissions | Required to bind each workspace Space to a native browser Tab Group so tabs remain isolated per Space and collapse when switching Spaces. |
| `bookmarks` | permissions | Required to persist Global Favorites, Spaces, pinned tabs, and nested folders inside `Other Bookmarks / Arcline` so user data survives browser restarts. |
| `history` | permissions | Required to query local browsing history inside Arcline's unified Command Bar New Tab page so users can find and reopen previously visited URLs alongside open tabs and Favorites. Never leaves the device. |
| `storage` | permissions | Required to save user preferences (language, theme, search engine, hover timing), Space themes, open folder states, archive history (`chrome.storage.local`), and ephemeral tab bindings (`chrome.storage.session`) locally. |
| `alarms` | permissions | Required to run periodic checks every 30 minutes to auto-archive idle temporary tabs without keeping a persistent background service worker alive. |
| `favicon` | permissions | Required to render cached website icons locally using the browser's built-in `_favicon` endpoint with zero third-party network calls. |
| `http://*/*`, `https://*/*` (`content_scripts` & `web_accessible_resources`) | host_permissions | Required to inject the lightweight left-edge hover detector (`overlay.js`) and mount the local sidebar overlay frame (`sidepanel.html`) on web pages. Never reads, modifies, or transmits page contents. |
