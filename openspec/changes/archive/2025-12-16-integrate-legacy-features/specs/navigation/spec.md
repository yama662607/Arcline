## ADDED Requirements
### Requirement: Space Tab Navigation
The system SHALL provide keyboard shortcuts to cycle through tabs *within the current space only*.

#### Scenario: Next Tab in Space
- **WHEN** user presses "Next Tab In Space" shortcut
- **THEN** active tab changes to the next visual tab in the sidebar list
- **AND** if at end of list, cycles to start

#### Scenario: Previous Tab in Space
- **WHEN** user presses "Prev Tab In Space" shortcut
- **THEN** active tab changes to the previous visual tab in the sidebar list
